## 🧠 Fundamentals:
Gained a solid understanding of voice agent components — Speech-to-Text (STT), Text-to-Speech (TTS), and LLMs — and how latency is introduced at each layer.

## 🏗️ Architectures & Trade-offs:
Explored different voice agent architectures, comparing modular pipelines vs. speech-to-speech APIs, and the trade-offs in flexibility, latency, and complexity.

## ⚡ Low-Latency Communication:
Learned how platforms like LiveKit minimize latency using optimized networking infrastructure and low-latency communication protocols.

## 🌐 Real-Time Connectivity:
Connected client devices to voice agents using WebRTC, and understood why it outperforms HTTP and WebSocket for low-latency audio streaming.

## 🎧 Conversational Flow Management:
Integrated Voice Activity Detection (VAD), end-of-turn detection, and context management to handle interruptions and maintain natural conversation flow.

## 🔄 Latency vs. Quality vs. Cost:
Investigated trade-offs between latency, audio quality, and cost by building a sample agent and experimenting with different voices.

## 📊 Performance Metrics:
Implemented latency measurement metrics across the voice pipeline and learned how to tune performance levers for faster and more responsive voice agents.
